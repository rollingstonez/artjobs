# 아트잡스 사이트맵과 분류 체계

순수예술 일자리 서비스 **아트잡스**의 범위, 분류, 메뉴 구조를 정리한 문서.
코드표의 실제 정의는 `src/types/job.ts`, DB 컬럼은 `supabase/migrations/`, 크롤러 분류기는 `scripts/crawler/common.py`에 있다. 세 곳은 항상 같은 코드를 써야 한다.

## 0. 아트잡스가 지키는 두 가지 (바로쌤에서 가져온 원칙)

분류 체계보다 먼저 정해 둔 서비스 원칙이다. 화면·DB·크롤러 어디를 고치든 이 둘을 깨지 않는다.

### 0-1. 내 집 근처 공고부터 보여준다

예술 일자리는 출퇴근·레슨·리허설처럼 몸이 가야 하는 일이 대부분이라, 거리가 곧 지원 가능 여부다.
바로쌤의 "우리 동네 우선"을 그대로 잇는다.

| 단계 | 방식 | 구현 |
|---|---|---|
| **1단계 ✅** | 사용자가 시·도 하나를 고르거나 "현재 위치로" 버튼으로 가장 가까운 시·도를 자동 선택. 목록·홈이 **같은 시·도 → 인접권(60km)·전국·온라인 → 그 밖** 순으로 정렬되고, 카드에 "내 지역 / 인접 지역" 표시 | `src/lib/location.ts`(정렬·거리), `src/components/NearMeBar.tsx`(설정 바), 쿠키 `artjobs_loc` |
| **2단계** | 공고의 근무지 주소를 지오코딩해 `lat`·`lng`를 채우면 화면이 자동으로 실제 거리(km)로 정렬·표시 | `supabase/migrations/0003_location.sql` (칸만 예약) |
| **2단계** | 로그인하면 마이페이지에서 "내 동네"를 계정에 저장하고, 관심 분야 + 내 동네 새 공고 알림 | `/me` |

**사용자 위치는 서버·DB에 저장하지 않는다.** 브라우저 쿠키에만 두고, 언제든 "해제"로 지운다. 좌표를 받았더라도 쿠키 밖으로 보내지 않는다.

### 0-2. 연락처를 공개하지 않고 메신저로 소통한다

구직자(예술가)의 전화번호·이메일은 화면에 절대 노출하지 않는다. 기관과 예술가는 **사이트 안 메신저**로만
연락을 주고받고, 개인정보는 본인이 원할 때 대화 안에서 직접 알려준다. 바로쌤이 학부모·선생님 사이에서
쓰는 방식과 같다.

| 대상 | 규칙 |
|---|---|
| 크롤링한 채용공고·오디션·공모 | 기관이 스스로 공개한 접수 창구(이메일·전화)는 원문대로 안내한다. 기관 정보이지 개인정보가 아니다 |
| 인재정보(구직 프로필) `/talents` — 2단계 | 이름(또는 활동명)·분야·장르·직무·지역·경력만 공개. 연락처 칸 자체를 두지 않는다. "메시지 보내기"로만 연결 |
| 기관이 직접 올리는 공고 `/post` — 2단계 | 기관은 접수 이메일을 공개할 수 있지만, 지원자는 메신저로 지원해도 된다 |
| 메신저 `/messages` — 2단계 | 로그인 사용자끼리 1:1. 신고·차단, 대화 보관 기간, 개인정보 처리방침에 명시. 크롤링 대상에는 구직자 인력풀·이력서 게시판을 절대 넣지 않는다(이미 정책) |

## 1. 범위: 어디까지 순수예술인가

기준은 **예술의전당(과 바로 옆 국립국악원) 무대·전시장에 정기적으로 오르는 장르**, 그리고 **학교 교과의 음악·미술·무용·국악·연극**이다. 기관으로 치면 한국문화예술위원회(ARKO)가 지원하는 장르에 해당한다.

| 서비스 | 우산 | 다루는 것 | 코드 |
|---|---|---|---|
| **아트잡스** | 예술의전당 · 국립국악원 · ARKO | 미술 · 음악 · 무용 · 국악 · 연극 | `family = fine` |
| **모던아트잡** (별도 서비스, 예정) | 콘텐츠진흥원(KOCCA) · 산업예술 | 실용음악·재즈 · 디자인 · 영화·방송영상·애니메이션 · 게임아트 · 방송댄스·스트릿댄스 · 웹툰 | `family = modern` |

두 서비스는 **저장소 하나, DB 하나, 도메인 둘**로 간다. 공고 행의 `family` 값으로 어느 서비스에 보일지 정한다. 지금은 아트잡스에만 집중하고, 모던아트잡은 코드표에 자리만 예약해 둔다.

### 회색지대 결정

애매하면 "예술의전당 무대나 전시장에 정기적으로 올라가는가"를 묻고, 아니면 모던아트잡으로 보낸다.

| 항목 | 결정 | 이유 |
|---|---|---|
| 뮤지컬 | 아트잡스 (연극 아래) | 오페라극장 단골 장르. 배우 오디션 방식이 연극과 같음 |
| 오페라 | 아트잡스 (연극 아래, 음악 탭에도 교차 노출) | 성악가·오케스트라·무대 스태프가 모두 얽힘 |
| 창극 | 아트잡스 (연극 아래, 국악 탭에도 교차 노출) | 국립극장 창극단. 소리꾼 오디션이 중심 |
| 한국무용 | 아트잡스 (무용 아래, 국악 탭에도 교차 노출) | 무용과 3전공(발레·현대·한국) 관행 |
| 서예 | 아트잡스 (미술 아래) | 예술의전당 서예박물관 |
| 사진 | 아트잡스 (미술 아래) | 작가·전시 사진. 상업 촬영 스태프는 나중에 모던으로 |
| 디자인 | 모던아트잡 | 한가람디자인미술관이 있지만 채용은 거의 기업 |
| 영상연기(드라마·영화) | 모던아트잡 | 소속사·제작사 오디션이라 무대 연기와 시장이 다름 |
| 실용음악·재즈 | 모던아트잡 | 예술의전당 정기 장르가 아님 |
| 문학 | 제외 | ARKO 장르이긴 하나 일자리 형태가 다르고 예술의전당 우산 밖 |

## 2. 분류: 네 축

한 공고를 **분야 · 장르 · 직무 · 게시판**의 조합으로 설명한다. "국악 분야 + 음향 스태프 + 채용공고"처럼 조합 검색이 되고, 직무 6개를 다섯 분야에서 재사용한다.

### 2-1. 분야(field)와 장르(genre)

장르 코드 앞에는 항상 분야 코드가 붙는다(`music_strings`). 장르만 봐도 분야를 알 수 있고, 크롤러가 장르를 잡으면 분야는 자동으로 정해진다.

| 분야 | 코드 | 장르 |
|---|---|---|
| 미술 | `art` | 회화 `art_painting` · 조소·설치 `art_sculpture` · 판화·드로잉 `art_print` · 사진 `art_photo` · 미디어아트 `art_media` · 공예 `art_craft` · 서예 `art_calligraphy` |
| 음악 | `music` | 성악 `music_voice` · 피아노·건반 `music_piano` · 현악 `music_strings` · 관악 `music_winds` · 타악 `music_percussion` · 작곡·지휘 `music_composition` |
| 무용 | `dance` | 발레 `dance_ballet` · 현대무용 `dance_contemporary` · 한국무용 `dance_korean` |
| 국악 | `gugak` | 성악(판소리·민요·정가) `gugak_voice` · 현악(가야금·거문고·해금·아쟁) `gugak_strings` · 관악(대금·피리·태평소) `gugak_winds` · 타악(장구·사물) `gugak_percussion` · 작곡·지휘 `gugak_composition` · 연희(풍물·탈춤) `gugak_yeonhui` |
| 연극 | `theater` | 연극 `theater_play` · 뮤지컬 `theater_musical` · 오페라 `theater_opera` · 아동극·인형극 `theater_children` · 창극 `theater_changgeuk` |

**교차 노출**: 국악 탭에서는 한국무용·창극 공고도, 음악 탭에서는 오페라 공고도 함께 보인다(`GENRE_CROSSLINKS`). 저장은 한 곳에만 하고 보여줄 때만 겹친다.

### 2-2. 직무(role): 모든 분야 공통

| 코드 | 직무 | 예 |
|---|---|---|
| `performer` | 실연 | 작가 · 연주자 · 무용수 · 배우 · 소리꾼 |
| `creator` | 창작 | 작곡 · 안무 · 연출 · 극작 |
| `education` | 교육 | 강사 · 레슨 · 방과후 · 문화예술교육사 |
| `planning` | 기획·행정 | 큐레이터 · 학예 · 공연기획 · 홍보 · 행정 |
| `stage_tech` | 무대·기술 | 무대미술 · 조명 · 음향 · 의상 · 분장 · 무대감독 · 전시설치 |
| `assistant` | 보조·기타 | 어시스턴트 · 인턴 · 아르바이트 |

교육은 예술 전공자 일자리에서 가장 큰 덩어리라 반드시 별도 직무로 둔다. 예전 미술 전용 코드였던 큐레이션·아트매니지먼트·예술교육은 장르가 아니라 직무로 옮겼다.

### 2-3. 게시판(board)

| 코드 | 게시판 | 경로 | 내용 | 단계 |
|---|---|---|---|---|
| `job` | 채용공고 | `/jobs` | 기관·단체·학교가 사람을 뽑는 공고 | 1 |
| `audition` | 오디션·공모 | `/auditions` | 단원 모집 오디션 · 콩쿠르 · 공모전 · 레지던시 · 창작지원사업 | 1 |
| `event` | 공연·전시 | `/events` | 공연·전시 일정 안내 | 3 |

채용공고와 오디션·공모는 둘 다 "기관이 올리는 공고"라 **같은 테이블, 같은 크롤러, 같은 화면**을 쓴다. 다른 건 `board` 값 하나뿐이다.

### 2-4. 고용형태(employment_type)

정규직 `full_time` · 계약직 `contract` · 프리랜서 `freelance` · 인턴 `intern` · 공모·지원사업 `open_call`

## 3. 사이트맵

```
아트잡스 (artjobs.kr)
├─ 홈 /                          내 동네 설정 바 · 분야별 건수 · 내 근처 채용공고 · 내 근처 오디션·공모 · 지키는 것 3가지
├─ 채용공고 /jobs                  [1단계 ✅]
│   ├─ 내 동네 설정 바 (쿠키 artjobs_loc) → 가까운 순 정렬, 카드에 "내 지역/인접 지역"
│   ├─ 분야 탭: 전체 · 미술 · 음악 · 무용 · 국악 · 연극      ?field=
│   ├─ 필터: 장르 · 직무 · 고용형태 · 지역 · 검색            ?genre= &role= &employmentType= &region= &q=
│   └─ 상세 /jobs/[id]
├─ 오디션·공모 /auditions           [1단계 ✅]
│   ├─ 내 동네 설정 바 · 분야 탭 · 필터 (채용공고와 동일)
│   └─ 상세 /auditions/[id]
├─ 인재정보(구직) /talents          [2단계] 회원가입·개인정보 처리 필요. 연락처 비공개, 메신저로만 연결
│   ├─ 프로필 검색: 분야 · 장르 · 직무 · 지역 (내 동네 우선)
│   ├─ 프로필 상세 /talents/[id]     "메시지 보내기" 버튼만, 전화·이메일 없음
│   └─ 내 프로필 등록·수정 /talents/new
├─ 메신저 /messages                 [2단계] 기관 ↔ 예술가 1:1 대화. 신고·차단
│   └─ 대화방 /messages/[id]
├─ 레슨·강사 /lessons               [선택] 시간 단위 거래라 채용과 분리
├─ 공연·전시 /events                [3단계] 매일 채워야 하는 운영 부담 큼
├─ 분야 홈 /art /music /dance /gugak /theater   [2단계] 검색 유입용 랜딩. 지금은 /jobs?field= 로 대신
├─ 공고 등록 /post                  [2단계] 기관·단체가 직접 올리는 창구
├─ 마이페이지 /me                   [2단계] 내 동네(계정 저장) · 관심공고 · 마감 알림 · 내 동네 새 공고 알림
└─ 소개 /about · 이용약관 · 개인정보 · 출처정책
```

상단 메뉴는 **게시판 종류**(채용공고 · 오디션·공모 · 인재정보 · 공연·전시)로 두고, 각 게시판 안에서 분야 탭을 고른다. 분야를 상단에 두면 메뉴가 5×4로 폭발한다.

## 4. 단계

1. **1단계(지금)** 채용공고 + 오디션·공모 + 내 동네 우선 정렬(쿠키). 크롤러가 모으는 공고만으로 돌아간다. 로그인 없음.
2. **2단계** 인재정보(구직), 메신저, 공고 직접 등록, 마이페이지(내 동네 계정 저장·알림), 근무지 지오코딩. Supabase 로그인과 개인정보 처리방침이 먼저 필요하다. 메신저가 열리기 전에는 인재정보를 열지 않는다(연락처를 노출할 다른 길이 없어야 하므로).
3. **3단계** 공연·전시 안내, 레슨, 커뮤니티. 공고가 어느 정도 쌓인 뒤.

## 5. 예전 코드에서 옮기기

| 예전 `category` | 새 축 |
|---|---|
| painting / sculpture_installation / media_art / print_drawing / craft / photography | `field=art` + 장르 `art_*` |
| curation / art_management | `field=art` + `role=planning` |
| art_education | `field=art` + `role=education` |
| residency_open_call | `board=audition` |

DB 변환 SQL은 `supabase/migrations/0002_taxonomy.sql`에 있다. 근무지 좌표 칸은 `0003_location.sql`.
